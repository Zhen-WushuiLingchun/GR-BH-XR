# BBH Runtime Architecture Decision

Status: preregistered decision logic implemented. The Task 8 two-resolution NR
pilot can qualify the keyframe architecture, but a complete time-indexed asset
and any surrogate training corpus remain separate fail-closed gates.

## Fixed budgets

- 72 Hz physics-render p95: `< 11.0 ms`.
- 90 Hz physics-render p95: `< 9.0 ms`.
- OpenXR total-frame p95 remains a device-only gate and is not inferred from
  synthetic stereo.

At `1832 x 1920` per eye on the RTX 5080 Laptop GPU, sequential synthetic
stereo measured `10.188 ms` p95 for the stationary fast path and `2655.530 ms`
for the full dynamic BBH path. The dynamic path is therefore an offline audit
kernel at native eye resolution, not a realtime XR renderer.

## Decision

| Hardware/use | Default | Evidence boundary |
| --- | --- | --- |
| High-end PCVR | time-indexed NR transfer keyframe architecture after Task 8 | the bounded pilot qualifies the architecture, not a complete merger asset; stationary fast-path timing is a proxy, and actual keyframe/OpenXR total-frame timing remains unmeasured |
| Desktop interactive | stationary display plus asynchronous progressive exact updates | cadence cost is an estimate until a tiled implementation is timed |
| Offline audit | full-resolution dynamic four-dimensional tracing | exact runtime path, no realtime claim |
| Quest Android | not evaluated | no native-device timing evidence |

Foveation alone is not selected. With only `0.812 ms` of stationary 72 Hz
headroom at the representative extent, the dynamic increment would have to be
restricted to roughly `3.1e-4` of the full image under an optimistic linear
pixel-cost model. This is too small to cover a physically useful critical
region and remains an estimate, not a measured VRS result.

Progressive updates are allowed only as stale-aware asynchronous refinement.
Each tile must carry metric time/phase and validity; an old tile must never be
silently presented as current dynamic spacetime evidence.

## Surrogate gate

No surrogate is selected or trained in this task. The two-resolution pilot
qualifies the producer pipeline but is not a training corpus. Training becomes
eligible only after a separately accepted exact transfer-buffer dataset is
available. A future surrogate must output event, escape direction, redshift,
time delay, image order, and uncertainty. Final RGB alone is forbidden as the
sole target, and out-of-distribution states must fail closed to exact tracing
or accepted keyframes.
